# VT-Labs

Лабораторные работы и учебные материалы за время обучения на факультете
системного и прикладного программного обеспечения Университета ИТМО.

> Материалы публикуются для ознакомления. При использовании указывайте автора.

## Объединённые репозитории

В июле 2026 года отдельные публичные репозитории с лабораторными работами были
перенесены сюда и заархивированы. В `VT-Labs` теперь находятся их актуальные
версии:

- `prog-lab-5`, `prog-lab-6` → [`java/lab5`](java/lab5), [`java/lab6`](java/lab6)
- `web-1` … `web-4` → [`web/lab1`](web/lab1) … [`web/lab4`](web/lab4)
- `itmo-fp-lab1` … `itmo-fp-lab4` → [`fp/lab1`](fp/lab1) … [`fp/lab4`](fp/lab4)
- `is-lab1` … `is-lab3` → [`is/lab1`](is/lab1) … [`is/lab3`](is/lab3)
- `os-lab4` → [`os/lab4`](os/lab4)
- `tpo-lab1` … `tpo-lab4` → [`tpo/lab1`](tpo/lab1) … [`tpo/lab4`](tpo/lab4)
- `rshd-lab1`, `rshd-lab2` → [`rshd/lab1`](rshd/lab1), [`rshd/lab2`](rshd/lab2)
